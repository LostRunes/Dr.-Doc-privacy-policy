# Dr. Doc: privacy policy

The public privacy policy for [Dr. Doc](https://github.com/LostRunes/transform.exe), the offline file converter and editor for Windows.

**Live page:** https://lostrunes.github.io/Dr.-Doc-privacy-policy/

It's a single static page (`index.html`), served by GitHub Pages from the `main` branch. Fonts (Silkscreen, Nunito) are bundled under the SIL Open Font License; see `assets/OFL-*.txt`.

To update the policy, edit `index.html`, change the "Last updated" date, and push.
